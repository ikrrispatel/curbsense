1. Lock the eight-task synthetic contract and public submission requirements.
2. Separate visible packets, hidden grader data, and physical references.
3. Implement and validate the deterministic evidence decision engine.
4. Wire and validate all deterministic camera assets.
5. Add parser, domain, safety, runner, and reproducibility golden tests.
6. Run the mock suite twice from clean copies and compare deterministic hashes.
7. Run clean repeated trials with at least one frontier and one smaller/open model only after deterministic gates pass.

Definition of done requires every reference to pass, deliberate failures to fail for the right category, clean-copy reproducibility, no secrets, pinned dependencies, human review, and honest model evidence.
