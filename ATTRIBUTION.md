# Attribution and adaptation record

Original repository: `https://github.com/BRYANN2K/llm-engineering-benchmark` by Bryan N., MIT licensed.

Reused patterns: frozen task manifests, task/prompt/model/grader/environment hashing, a model-runner boundary, timeout and runner-error separation, immutable run artifacts/checksums, validation, golden tests, deterministic reports, and reproducibility packaging.

Removed or replaced: coding-agent tasks, starter repositories, Git patch evaluation, Hermes runtime and tool sandbox assumptions, software-engineering graders, private-repository grader commitments, route/pricing logic, generic leaderboard claims, and unrelated historical reports.

New CurbSense work: eight synthetic curb/parking evidence packets, deterministic SVG camera assets, evidence-reference and temporal validation, permit/payment/zone/grace rules, unsafe-action and abstention categories, calibration metrics, mock and HTTP-compatible adapters, transcripts, and submission documentation.

AI tools assisted with implementation and drafting. Human review is required for every task, reference answer, rubric rule, transcript, and result before submission.
